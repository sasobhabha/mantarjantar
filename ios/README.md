# Jantar Mantar Chalo — iOS / iPadOS / Mac Catalyst

Port of the Android app (`com.jantarmantarchalo.app`). Like the Android version,
this is a native shell around the game's web client:

- **Online**: loads the live game at `https://mantarjantar.com` (multiplayer
  works, same server as the website and the Android app).
- **Offline**: if the live site can't be reached, it automatically falls back to
  the bundled copy of the web client (`WebAssets/`), where **Practice (offline)**
  mode works with no network at all — served through a custom `jmclocal://`
  `WKURLSchemeHandler` (the equivalent of Android's
  `WebViewAssetLoader` + `appassets.androidplatform.net`).
- The user agent gets `JantarMantarChaloApp` appended (same trick as the
  Android app) so the page hides its "Get the Android app" banner.
- Screen stays awake during play; status bar hidden; all orientations supported.

## Project layout

```
ios/
  project.yml            # XcodeGen manifest (regenerate with `xcodegen generate`)
  Sources/               # SwiftUI + WKWebView wrapper
  WebAssets/             # bundled copy of the web game (from ../assets)
  Assets.xcassets/       # app icon (single-size 1024px)
  Tools/make_icon.py     # regenerates the cockroach icon (python3 Tools/make_icon.py)
```

## Build & run

Requires Xcode. The `.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```sh
cd ios
xcodegen generate          # after changing project.yml or adding files
open JantarMantarChalo.xcodeproj
```

- **iOS/iPadOS**: select the `JantarMantarChalo` scheme + an iOS Simulator or
  device. For a device/App Store build, set your team & bundle id
  (Signing & Capabilities); the default id is `com.jantarmantarchalo.app`.
- **Mac Catalyst**: destination "My Mac (Mac Catalyst)" — supported via
  `SUPPORTS_MACCATALYST`. Cmd+R reloads the game.

Debug hooks:
- Launch argument `-JMCOffline` forces the bundled copy (tests the offline path).
- Debug builds log navigation/fallback to `tmp/jmc.log` in the app container
  (`xcrun simctl get_app_container <device> com.jantarmantarchalo.app data`).
